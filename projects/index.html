Rust Runtime for AI Agents

Creator

A durable execution runtime in Rust for nondeterministic AI agents. It journals every model call and tool call to a tamper-evident log, so a crashed run resumes exactly where it stopped without repeating finished work, and any run can be replayed faithfully for debugging and audit.

Zero-dependency core with Python bindings and a CLI, plus independent anchoring of the log and evidence bundles an auditor can verify offline.

Hypnagogia

Creator

A whole-brain Drosophila simulation built to test whether a learned memory reactivates on its own during sleep.

144,209 neurons and 21,868,062 connections from the male CNS connectome, integrated cell by cell in Brian2 and scored against shuffled-connectome and unlearned-weights controls, with negative results reported in full.

Aperta

Co-creator

A clinician pastes the discharge note they already wrote, and Aperta turns it into what the patient understands at home: a hand-drawn body marking the place, one plain sentence for what happened, every medicine with what it is for and how to take it, and walkthroughs for the steps a note assumes you know, in the patient's language.

Nothing clinical is generated; the parsing and drug checks are deterministic code running in the page. Built at VTHacks 14.

Graphite

Creator

A 3D graphing calculator that runs entirely in the browser.

It plots function, cylindrical, spherical, parametric, and implicit surfaces alongside space curves and vector fields, with click-to-inspect calculus tools for tangent planes, symbolic partial derivatives, gradients, divergence and curl, level curves, Riemann sums, and animated Frenet frames. The expression parser, symbolic differentiation, and marching cubes geometry are written from scratch with no dependencies.

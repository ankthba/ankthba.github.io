Pragmatic

Founder · Jan 2026 – Present · Pragmatic Research, Inc.

The system of record for AI agents: every model and tool call journaled, so a run can be replayed exactly or resumed where it stopped.

Underneath is a zero-dependency durable execution runtime in Rust, with agent execution and replay formalized in a probabilistic process calculus. Its append-only journal takes 230 ns per append, with flat latency through one million entries, and passes a 1000/1000 replay-determinism test suite. Incorporated as a Delaware C-corp in August 2026.

      Add a free Cesium ion token

      This map streams Google's photorealistic 3D tiles through Cesium ion, so it needs a token from your own (free) account.

      1. Sign up at ion.cesium.com (Community plan).
      2. Open Access Tokens and copy the Default token.
      3. Copy viewer/key.example.js to viewer/key.js and paste the token in.
      4. Reload this page.

      A Google Maps key with the Map Tiles API works too (window.GMAPS_KEY), but Google asks for billing.

What teams build on Pragmatic, and the three ways to run it.

What you build on it

Agents that run for days.

Long-running agents survive process restarts, deploys, and infrastructure failures, then resume exactly where they stopped. No re-sampling and no half-finished work.

Bugs you can finally replay.

Reproduce the exact run that failed, step by step, including the nondeterministic model behavior that caused it. Bugs you could never reproduce become runs you can replay.

Runs you can prove.

Every run has a signed, replayable record of what the agent actually did. That reproducibility matters most for regulated and high-stakes teams, and it is built into the runtime.

Fleets that fail gracefully.

When one agent in a system crashes, recover it from its Journal without unwinding the others. Coordinated multi-agent runs stay consistent through partial failure.
